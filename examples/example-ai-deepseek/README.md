# DeepSeek + Insights AI Examples

Track DeepSeek API calls with Insights via the OpenAI-compatible API.

## Setup

```bash
pnpm install
cp .env.example .env
# Fill in your API keys in .env
```

## Examples

- **chat.ts** - Chat completions via DeepSeek

## Run

```bash
source .env
npx tsx chat.ts
```
