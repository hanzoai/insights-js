# Fireworks AI + Insights AI Examples

Track Fireworks AI API calls with Insights via the OpenAI-compatible API.

## Setup

```bash
pnpm install
cp .env.example .env
# Fill in your API keys in .env
```

## Examples

- **chat.ts** - Chat completions via Fireworks AI

## Run

```bash
source .env
npx tsx chat.ts
```
